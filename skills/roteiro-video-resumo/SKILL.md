# Roteiro de vídeo-resumo

## Entrada
- Material da unidade (e-book, resumo ou transcrição)
- Duração desejada (60, 90 ou 120 s)
- Formato (vertical 9:16 ou horizontal 16:9)

## Regras
1. **~150 palavras por minuto** de narração.
2. Só ideias do material. Nada de promessa ou dado novo.
3. Uma ideia por cena; texto na tela com no máximo 6 palavras.
4. Siglas e nomes difíceis escritos **como se falam** na narração (para voz sintética).

## Estrutura
| Cena | Tempo | Narração | Texto na tela | Imagem/animação |
|---|---|---|---|---|
| 1 Gancho | 0–5 s | pergunta ou situação que o aluno vive | | |
| 2–4 Ideias | | uma ideia central por cena | | |
| 5 Exemplo | | aplicação prática | | |
| 6 Fechamento | | "agora pratique: …" | | |

## Saída
A tabela acima + a narração corrida em um bloco único (para colar no gerador de voz).

## Como usar fora do Claude
Cole este arquivo, depois o material, a duração e o formato.
