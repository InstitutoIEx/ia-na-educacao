# Como contribuir

Obrigado por querer melhorar a IA na educação em português! 💛

## Formas de ajudar
- **Relato de uso:** abra uma *Issue* contando onde usou, para que público e o que funcionou ou não.
- **Melhoria:** encontrou um prompt que inventa fonte, ignora uma regra ou poderia ser mais claro? Abra uma *Issue* ou um *Pull Request*.
- **Skill nova:** crie uma pasta em `skills/nome-da-skill/` com um `SKILL.md`.

## Padrão de uma skill
```
---
name: nome-em-minusculas-com-hifen
description: O que faz e QUANDO usar (1–2 frases).
---
# Título
## Entrada
## Regras
## Passos / Estrutura
## Saída
## Como usar fora do Claude
```

## Regras do repositório
1. **Nada de dados pessoais** (alunos, professores, pacientes) em exemplos.
2. **Nada de fonte inventada**: exemplos com citação precisam ser reais.
3. Português do Brasil, linguagem simples.
4. Ao contribuir, você concorda que seu texto seja publicado sob CC BY 4.0 e o código sob MIT.

## Código de conduta
Respeito, acolhimento e foco no aprendizado. Ataques pessoais e discriminação não são tolerados.
